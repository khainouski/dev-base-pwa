# DevBase

Личное PWA для подготовки к техническим собеседованиям: вопросы и собственные ответы,
у каждого вопроса две кнопки к AI — **Пример** и **Уточнить**.

- Две папки: **Company** (вопросы под конкретную компанию) и **General** (общая подготовка).
- Текст — обычные markdown-файлы из `data/md/`, те же, в которых конспект и пишется.
- Поиск по всем вопросам, офлайн, установка на домашний экран.
- Ключ к Claude или Gemini вводится в настройках и хранится только в этом браузере.

```bash
npm run dev    # http://localhost:3000
```

Без сборки, без зависимостей, без бэкенда. Деплой — Vercel, Framework Preset «Other»,
пустые build command и output directory.
